`CREATE SCHEMA IF NOT EXISTS "drizzle"` every 33 seconds.

## Verified behaviour

| Claim                                   | How it was checked                                           | Result                                            |
| --------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------- |
| Hi-res is fetched when offered          | app's own `resolveStream` → download → decrypt → probe, live | 24-bit/96 kHz, 134.7 MiB                          |
| Falls back when not offered             | same path, a CD-only release                                 | 16-bit/44.1 kHz, no failure                       |

| Upgrade engine works                    | `findBestUpgrade` over 20 real candidates                    | 5 upgradeable, 15 already best                    |

finds upgrades when they exist.

## Security

| Area                  | Status                                                                                                                                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Auth on new endpoints | `locals.user` checked on `/api/diagnostics` and `/api/tracks/upgrade-all`; both inherit the hook's origin check and per-user rate limit                                                                       |
| SQL injection         | none possible — every new query is drizzle-parameterised; the hand-written `sql` fragments contain only column references and one constant                                                                    |
| CSRF                  | origin check on all non-GET `/api`; new POST is covered                                                                                                                                                       |
| Path traversal        | `sanitizeComponent` strips `/`, `\`, `..`, control and bidi characters on every provider-supplied path component; zip extraction explicitly treats archives as hostile                                        |
| Command injection     | `execFile` with an argument array, no shell, for `metaflac`                                                                                                                                                   |
| Secrets in new output | **fixed** — `errorSignature` redacts every `key=value` in a URL query. Deezer's CDN signs with `hdnea`/`acl`/`hmac`, none of which match a credential-shaped allowlist, and the values are live access tokens |
| New index/scan risk   | none — every new query is under 4 ms on 1290 rows / 6272 jobs                                                                                                                                                 |

### Accepted, not fixed

- **`sameOriginOk` compares host only, not scheme.** An `http://` origin on the
  same host passes. Behind TLS termination with `USE_SECURE_COOKIES=true` the
  cookie is not sent over http anyway, so this is defence-in-depth being weaker
  than its comment implies, not an exploitable path. Fixing it risks breaking
  legitimate proxy topologies.
- **`getClientIp` trusts `x-forwarded-for` verbatim.** An anonymous client can
  mint fresh rate-limit buckets. Authenticated requests are still keyed by user
  id, so this only affects the unauthenticated surface.
- **`ILIKE '%term%'` cannot use an index.** 3.3 ms at this size. A trigram index
  is the answer only past ~50k rows.

## Performance

Measured with `EXPLAIN (ANALYZE, BUFFERS)` on the real data — worst case 3.3 ms
(the search path), everything else sub 2 ms. `trackStats` went from 4 queries to
9 to serve the tier breakdown; that is the price of the filter agreeing with its
chips, and it is invisible at this scale.
